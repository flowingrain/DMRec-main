# 图片目录

## 需要的图片文件

请将以下图片文件放置在此目录：

1. **reflowrec_model.pdf**: ReFlowRec 模型架构图
   - 展示：Collaborative Space, Language Space, Rectified Flow Matching, Reflow 机制
   - 参考：DMRec 的 model.pdf，但突出 Rectified Flow 的特点

2. **ablation_*.pdf**: 消融实验图
   - amazon_ablation.pdf
   - yelp_ablation.pdf  
   - steam_ablation.pdf

3. **parameter_*.pdf**: 超参数敏感性分析图
   - amazon_param.pdf
   - yelp_param.pdf
   - steam_param.pdf

4. **sparsity_*.pdf**: 稀疏性分析图（可选）
   - amazon_sparsity.pdf
   - yelp_sparsity.pdf
   - steam_sparsity.pdf

5. **inference_speed.pdf**: 推理速度对比图（可选）

## 图片生成建议

可以使用以下工具生成：
- Python + matplotlib
- TikZ (LaTeX)
- 其他绘图工具

参考 DMRec 的图片风格，保持一致性。
